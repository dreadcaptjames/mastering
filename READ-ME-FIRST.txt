MASTERFORGE AI WEB STUDIO v1.0 BETA — DYNAMIC SIGNATURE

The root files host the browser-native MasterForge studio (GitHub Pages/Netlify).
The fully local browser DSP now provides whole-song 2-second section analysis,
dynamic EQ and gain, conditional compression, approximate integrated LUFS metering,
guarded stereo width, and peak protection. It supports all four styles, six palettes,
four aesthetics, saved startup settings, waveform scrubbing, A/B and WAV/MP3/M4A exports.

Signature + Streaming (-14 LUFS) is the default for new users. Choose any settings
and use Save current as default to remember them in this browser.

Audio processing in Local mode stays on the user's device. It is NOT the same binary
as the desktop Python/FFmpeg engine, and sonic parity has not been established.
The browser LUFS / intersample-peak measurements are estimates, not certified meters.
M4A export depends on native browser support. MP3 may require encoder download.
Large audio can exhaust device memory; there is no fixed duration limit.
No AI model is involved: the engine is rule-based adaptive DSP.

Upload ALL root files (including web-mastering.js, app.js, index.html, theme.js,
styles.css, sw.js, manifest.webmanifest and assets/) to the static host, then
reopen the installed web app while online to refresh its service worker cache.
The complete Python desktop application remains unchanged under desktop/.
